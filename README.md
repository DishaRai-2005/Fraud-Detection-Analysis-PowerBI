# Fraud Detection and Analysis using Power BI

## Project Overview
An interactive Power BI dashboard developed to analyse financial transactions, identify fraudulent transactions, and understand transaction risk patterns.

## Dataset
- Total transactions: 50,000
- Fraud transactions: 83
- Genuine transactions: 49,917

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Fraud vs Genuine transaction analysis
- Transaction risk classification (High, Medium, Low)
- Monthly transaction trend analysis
- Transaction type analysis
- Device and location analysis
- Interactive slicers and KPI cards

## Key Findings
- 83 fraud transactions identified in the dataset.
- 49,917 genuine transactions.
- Fraud transactions represent approximately 0.166% of the dataset.
